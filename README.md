# FlowRecorder

轻量 Mac 录屏工具原型。定位不是“教学专用软件”，而是面向创作者、课程讲解、产品演示、作品复盘的通用录屏工具。

## 当前原型能力

- 原生 macOS App，Swift / SwiftUI / AppKit。
- 录制主屏幕画面。
- 可开启系统声音录制。
- 可开启麦克风录制；当前测试版默认关闭麦克风，先保证录屏和系统声音稳定。
- 支持录制范围选择：全屏、手动框选、16:9 横屏、9:16 竖屏、1:1 方形。
- 支持按窗口录制：可选择 PPT、微信、浏览器、Codex 等窗口，录制会跟随该窗口内容变化。
- 开始录制前默认提供 3 秒倒计时；倒计时期间可再次点击录制按钮取消。
- 支持导出清晰度：原画、最高 1080P、最高 720P、最高 540P。低于目标尺寸的画面不会被强行放大，非 16:9 画面保持原始比例。
- 支持多显示器：窗口或手动区域会自动匹配所在显示器；若开启的音频源未收到输入，保存后会明确提示。
- 圆形摄像头悬浮小窗，可拖动。
- 提词器悬浮窗，可在主界面编辑文案并同步。
- 输出文件保存到 ~/Movies/FlowRecorder。

## 当前快捷键

- Command + R：开始 / 停止录制。

## 首次运行权限

macOS 会拦截所有录屏软件。第一次使用时需要手动允许：

1. 打开系统设置。
2. 进入隐私与安全性。
3. 找到屏幕与系统音频录制。
4. 允许 FlowRecorder。
5. 退出并重新打开 FlowRecorder。

如果不开这个权限，应用会显示“没有屏幕与系统音频录制权限”，不会生成视频文件。

当前测试版建议先保持“麦克风”关闭，确认系统声音录制和视频保存稳定后，再打开麦克风测试讲解声音。

## 第一阶段不做

- Windows 版。
- App Store 上架。
- 云端上传。
- 剪辑功能。
- 自动字幕。
- 美颜。

## 下一步重点

- 将摄像头小窗真正合成进录制视频，而不是只依赖屏幕捕获可见窗口。
- 增加录制倒计时、录制小控制条、鼠标点击高亮。
- 打包成可双击安装/运行的 .app 或 .dmg。
